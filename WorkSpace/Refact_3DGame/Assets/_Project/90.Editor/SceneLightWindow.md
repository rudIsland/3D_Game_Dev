# 조명 소속 확인

`Tools > World > 조명 소속 확인` 또는 리소스 소속 창의 `조명 소속 확인` 버튼으로 연다.

## 사용 순서

1. Ground와 Underground를 Additive로 모두 연다.
2. 대상에 확인할 씬의 Setup&Lights를 지정한다. 처음에는 지상 환경 묶음을 찾는다. 지하는 Hierarchy의 Underground/Setup&Lights를 끌어 넣는다.
3. 분석을 누르면 Light, Volume, Reflection Probe, 환경 MeshRenderer를 읽고 지상 후보·지하 후보·확인 필요를 표시한다.
4. 이름을 누르면 해당 위치로 이동한다. 범위 전체 보기로 영향 범위를, 지상 주변 메시·지하 주변 메시로 가장 가까운 배치를 확인한다. Scene 뷰에서 조명 범위는 노랑, 지상 주변 메시 상자는 초록, 지하 주변 메시 상자는 청록이다.
5. 켜진 실시간 조명만 잠시 끌 수 있다. 선택 변경·창 닫기·씬 저장·스크립트 재컴파일·Play 진입 시 원래 켜진 상태로 복원한다. Mixed/Baked는 임시 끄기 대상이 아니다.
6. 분류표 저장으로 전체 분석 결과를 UTF-8 CSV에 저장한다. 위치·범위를 수정한 뒤에는 다시 분석한다.

## 판정 범위

- 지상·지하의 MeshRenderer 바깥 상자와 Terrain 범위를 읽는다. 비활성 객체와 각 LOD도 포함하며 이름에 Minimap이 포함된 부모 아래는 제외한다.
- Point는 구와 상자, Spot은 거리 및 보수적인 원뿔 범위, Local Volume은 활성 Collider 상자와 Blend Distance, Reflection Probe는 bounds를 비교한다.
- 벽의 차폐, 조명 레이어, 표면 삼각형, 실제 밝기와 베이크 결과는 계산하지 않는다. 교차 개수는 건물 수가 아니다.
- 태양·Global Volume·하늘·발광 메시는 위치만으로 소속을 정하지 않는다. 양쪽과 겹치거나 비교 씬이 빠진 경우에도 확인 필요로 남긴다.
- 분석 결과는 이동 명령이 아니다. 원본 배치·진입 시 켜던 묶음·실제 화면을 함께 확인해야 한다.

분석은 버튼을 누를 때만 실행하고 결과에는 객체 ID와 문자열·범위만 보관한다. 런타임 게임 코드와 씬 배치에는 분석 기능이 추가되지 않는다.
