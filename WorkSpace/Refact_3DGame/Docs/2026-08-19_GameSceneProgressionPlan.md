# GameScene 게임 진행 보고서

## 1. 보고서 목적

이 문서는 현재 `GameScene`에 준비된 지상과 지하 지형을 사용하여 게임을 어떤 순서로 진행할지 정리한다.

첫 완성 목표는 일반몹과 정예몹을 상대하며 지하 입구를 찾고, 지하의 보스를 처치하면 끝나는 30~45분 분량의 간단한 소울라이크 게임이다.

## 2. 현재 준비 상태

현재 프로젝트에는 다음 요소가 준비되어 있다.

- 일반몹: `Zombie`
- 정예몹: `NightShadeSwordElite`
- 보스 외형과 애니메이션: `DemonSwordsmanBoss`
- 플레이어 이동, 공격, 구르기, 방어, 락온과 스태미나
- 플레이어와 적의 체력·스태미나·경직 HUD
- 지상 숲과 폐허, 지하 묘실, 보스방이 포함된 `GameScene`
- 시작점, 체크포인트, 전투 지점과 보스 지점을 표시하는 `LevelFlow`

다음 기능은 아직 실제 게임 진행 기능으로 연결되지 않았다.

- `GameScene`의 플레이어와 플레이 카메라 배치
- 구역별 일반몹과 정예몹 생성
- 체크포인트 저장과 플레이어 부활
- 묘실 열쇠 획득과 지하 문 개방
- 보스 전투 시작과 보스방 잠금
- 보스 처치 후 엔딩 처리

## 3. 전체 게임 진행 순서

```text
지상 시작
→ 숲길에서 일반몹 전투
→ 숲 교차로 체크포인트 발견
→ 서쪽 폐허에서 지하 열쇠에 관한 단서 발견
→ 동쪽 폐허에서 정예몹 처치
→ 묘실 열쇠 획득
→ 지하 입구 개방
→ 지하 통로 탐색
→ 지하 체크포인트 발견
→ DemonSwordsman 보스전
→ 보스 처치 문구와 엔딩 화면
```

## 4. 구역별 진행 계획

### 4.1 시작 지점

- 사용 위치: `StartPoint_Default`
- 플레이어와 카메라가 이 위치에서 시작한다.
- 이동, 공격, 구르기, 방어와 락온 조작을 짧은 화면 문구로 안내한다.
- 좀비를 한 번에 한 마리씩 배치하여 기본 전투를 익히게 한다.

시작 문구:

> 종이 멎은 날, 죽은 자들이 숲으로 걸어 나왔다.

### 4.2 숲 교차로

- 사용 위치: `SavePoint_ForestCrossroad`
- 플레이어가 처음 발견하는 체크포인트다.
- 체크포인트를 사용하면 체력과 스태미나를 회복하고 마지막 부활 위치를 갱신한다.
- 서쪽 폐허와 동쪽 폐허로 갈라지는 탐색 기준점으로 사용한다.

### 4.3 서쪽 폐허

- 사용 위치: `FarmPoint_WestRuins`
- 좀비를 배치하여 짧은 선택 전투 구역으로 만든다.
- 시체, 부서진 무기 또는 짧은 문구를 통해 묘실 열쇠가 동쪽 폐허에 있다는 사실을 알려준다.
- 반드시 방문해야 하는 구역은 아니며, 플레이어가 길을 찾도록 돕는 단서 구역으로 사용한다.

단서 문구:

> 묘실 열쇠는 동쪽 폐허의 검은 기사에게 넘겨졌다.

### 4.4 동쪽 폐허

- 사용 위치: `FarmPoint_EastRuins`
- 일반몹 한두 마리를 먼저 배치하고, 안쪽의 넓은 공간에 정예몹을 배치한다.
- 정예몹 `NightShadeSwordElite`를 처치하면 묘실 열쇠를 획득한다.
- 열쇠는 사망하더라도 잃어버리지 않는다.

획득 문구:

> 묘실 열쇠를 얻었다.

### 4.5 지하 입구

- 사용 위치: `BossEntrance_Underground`
- 열쇠가 없으면 문이 열리지 않고 잠겨 있다는 문구를 표시한다.
- 열쇠가 있으면 지하 문을 열고 이후에는 사망하더라도 열린 상태를 유지한다.
- 횃불과 계단을 사용하여 플레이어의 시선이 자연스럽게 지하로 향하게 한다.

개방 문구:

> 썩은 봉인이 열렸다.

### 4.6 지하 통로

- 좁은 길에는 좀비를 여러 마리 동시에 배치하지 않는다.
- 모퉁이, 기둥과 계단 뒤에 한 마리씩 배치하여 긴장감을 만든다.
- 횃불, 피 흔적과 시체 방향을 사용하여 보스방으로 가는 길을 안내한다.
- 지상과 지하의 적이 서로 감지하지 않도록 지하 진입 이후에 지하 적을 활성화한다.

지하 진입 문구:

> 땅 아래에서 멎은 종소리가 다시 울린다.

### 4.7 지하 체크포인트

- 보스방 입구 앞 안전한 공간에 두 번째 체크포인트를 추가한다.
- 플레이어가 보스전에서 사망했을 때 긴 지하 통로를 반복하지 않도록 한다.
- 체크포인트 사용 시 체력, 스태미나와 추후 구현할 회복약을 충전한다.

### 4.8 보스방

- 사용 위치: `BossRoom_Underground02`
- 플레이어가 보스방 안으로 들어오면 입구를 닫고 보스 전투를 시작한다.
- `DemonSwordsmanBoss`를 최종 보스로 사용한다.
- 보스가 살아 있는 동안에는 보스방을 나갈 수 없다.
- 플레이어가 사망하면 보스 체력과 전투 상태를 초기화한다.
- 보스를 처치하면 입구를 다시 열고 엔딩 화면을 표시한다.

엔딩 문구:

> 검귀가 쓰러지자 지상의 신음도 멎었다.

## 5. 입력 → 처리 → 출력 흐름

### 일반 진행

```text
플레이어 이동 입력
→ 구역 진입과 적 감지
→ 일반몹·정예몹 전투
→ 단서 또는 열쇠 상태 변경
→ 다음 목표 문구 출력
```

### 지하 문 상호작용

```text
지하 문 상호작용 입력
→ 묘실 열쇠 보유 여부 확인
→ 열쇠가 없으면 잠김 문구 출력
→ 열쇠가 있으면 문을 열고 지하 진입 허용
```

### 플레이어 사망과 부활

```text
플레이어 체력 0
→ 사망 애니메이션
→ 화면 암전
→ 마지막 체크포인트 확인
→ 플레이어 위치·체력·스태미나 초기화
→ 일반몹·정예몹과 진행 중이던 보스 초기화
→ 화면을 밝히고 조작 재개
```

### 보스 처치

```text
보스 체력 0
→ 보스 공격과 이동 중지
→ 사망 애니메이션
→ 보스방 잠금 해제
→ 엔딩 문구 출력
→ 처음부터 또는 게임 종료 선택
```

## 6. 다음 구현 순서

1. `GameScene`에 플레이어, 플레이 카메라와 HUD를 연결한다.
2. 시작점에서 보스방까지 직접 이동하며 바닥, 계단, 벽과 카메라 충돌을 확인한다.
3. 지상 구역에 일반몹과 정예몹 생성 위치를 배치한다.
4. 숲과 지하 체크포인트, 플레이어 부활을 구현한다.
5. 정예몹 처치, 묘실 열쇠와 지하 문을 연결한다.
6. 지하 통로의 적 생성과 구역 활성화를 연결한다.
7. DemonSwordsman 보스 전투를 구현한다.
8. 보스 처치와 엔딩 화면을 연결한다.

## 7. 첫 완성 범위에서 제외할 기능

첫 완성본에서는 진행 흐름과 전투 완성에 집중하기 위해 다음 기능을 제외한다.

- 경험치와 레벨업
- 장비와 인벤토리
- 화폐와 사망 위치 회수
- NPC 대화와 컷신
- 여러 엔딩
- 디스크 저장과 이어하기
- 미니맵
