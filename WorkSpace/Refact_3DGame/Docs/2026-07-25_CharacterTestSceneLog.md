# 캐릭터 테스트 씬 구현 기록

- 작업 날짜: 2026-07-25
- 구현 기능: 캐릭터 개발용 테스트 씬과 충돌 검증 환경
- 개발 씬: `Assets/_Project/Scenes/Dev/CharacterTestScene.unity`

## 1. 구현 목표

기존 게임 씬과 원본 맵을 변경하지 않고 플레이어, 적, 이동과 충돌 기능을 독립적으로 확인할 수 있는 개발용 씬을 구성한다.

## 2. 인게임 맵 설정

캐릭터와 충돌되어야 하는 맵 오브젝트에 Collider를 구성했다. 반복적인 Collider 삽입 작업은 AI MCP를 사용하여 수행했다.

## 3. 캐릭터 배치

플레이어 구성:

- 플레이어 모델 배치
- `CharacterController` 연결
- 이동과 카메라 검증을 위한 `PlayerRoot` 구성

적 구성:

- Zombie 모델과 `CapsuleCollider` 배치
- Mutant 모델과 `CapsuleCollider` 배치
- Fighter 모델과 `CapsuleCollider` 배치

## 4. 이동 검증 환경

다음 환경에서 플레이어 이동과 충돌을 확인할 수 있도록 테스트 오브젝트를 구성했다.

- 평지
- 경사로
- 계단
- 점프 장애물
- 좁은 충돌 통로

## 5. 변경 범위

- 기존 `GameScene`은 수정하지 않음
- 원본 맵은 수정하지 않음
- 캐릭터 개발과 검증은 `CharacterTestScene`에서 진행

## 6. 결과

- 플레이어와 적 캐릭터를 한 씬에서 확인할 수 있는 개발 환경 구성
- 걷기, 달리기, 회전, 중력과 점프를 단계별로 검증할 수 있는 구조 구성
- 경사로, 계단과 좁은 통로에서 `CharacterController` 충돌을 확인할 수 있는 환경 구성

3. 카메라 방향 기준 이동 구현
